# Мини-социальная сеть на Flask

Учебное веб-приложение на Python для публикации коротких текстовых записей. Пользователь может зарегистрироваться, войти в аккаунт, заполнить описание профиля, просматривать публикации и редактировать или удалять свои записи.

## Возможности

- регистрация и вход по имени пользователя и паролю;
- общая лента публикаций, отсортированная от новых к старым;
- создание, просмотр, редактирование и удаление собственных публикаций;
- публичные профили с описанием пользователя и его публикациями;
- хранение пользователей и публикаций в SQLite.

## Используемые технологии

- Python;
- Flask;
- SQLite;
- HTML-шаблоны Jinja2;
- CSS.

## Запуск приложения

### Требования

Установленный Python и пакет Flask. В репозитории пока нет файла `requirements.txt`.

### Установка и запуск

1. Склонируйте репозиторий и перейдите в его папку:

   ```bash
   git clone https://github.com/Te-He-4eK/PP.git
   cd PP
   ```

2. При желании создайте и активируйте виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

   Windows:

   ```bash
   .venv\Scripts\activate
   ```

   macOS / Linux:

   ```bash
   source .venv/bin/activate
   ```

3. Установите Flask:

   ```bash
   python -m pip install Flask
   ```

4. Запустите приложение:

   ```bash
   python app.py
   ```

При запуске `app.py` функция `create_database()` создаёт файл `database.db` и необходимые таблицы, если их ещё нет. Затем Flask запускает локальный сервер в режиме отладки. Откройте адрес, указанный в консоли (обычно `http://127.0.0.1:5000/`).

## Основные страницы и маршруты

| Маршрут | Методы | Назначение | Доступ |
|---|---|---|---|
| `/` | GET | Общая лента публикаций | Всем |
| `/register` | GET, POST | Форма регистрации и создание аккаунта | Всем |
| `/login` | GET, POST | Форма входа | Всем |
| `/logout` | GET | Выход из аккаунта | Всем; очищает текущую сессию |
| `/create_post` | GET, POST | Создание публикации | Только вошедшему пользователю |
| `/my_posts` | GET | Список публикаций текущего пользователя | Только вошедшему пользователю |
| `/edit_post/<post_id>` | GET, POST | Просмотр формы и редактирование своей публикации | Только автору публикации |
| `/delete_post/<post_id>` | GET | Удаление своей публикации | Только вошедшему пользователю; удаление выполняется только для его записей |
| `/profile/<username>` | GET | Публичный профиль пользователя и его публикации | Всем |
| `/edit_profile` | GET, POST | Изменение описания своего профиля | Только вошедшему пользователю |

При попытке выполнить действие, требующее входа, приложение перенаправляет пользователя на страницу входа. Для ошибочных или пустых данных отображается страница с сообщением.

## База данных

Приложение использует SQLite и файл `database.db`, расположенный в рабочей папке приложения.

### Таблица `users`

| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER | Первичный ключ, увеличивается автоматически |
| `username` | TEXT | Имя пользователя |
| `password` | TEXT | Пароль пользователя |
| `about` | TEXT | Описание профиля; может быть пустым |

### Таблица `posts`

| Поле | Тип | Описание |
|---|---|---|
| `id` | INTEGER | Первичный ключ, увеличивается автоматически |
| `username` | TEXT | Имя автора публикации |
| `text` | TEXT | Текст публикации |
| `created_at` | TEXT | Дата и время публикации в формате `ДД.ММ.ГГГГ ЧЧ:ММ` |

При запуске `create_database()` проверяет наличие столбцов `about` и `created_at` и добавляет их в старую базу, если они отсутствуют.

## Основные сценарии работы

1. Новый пользователь открывает `/register`, вводит имя и пароль и отправляет форму.
2. После регистрации пользователь переходит на `/login` и входит в аккаунт.
3. На главной странице он может открыть форму создания публикации. Пустые публикации не сохраняются.
4. Свои публикации пользователь видит на `/my_posts`; оттуда их можно изменить или удалить.
5. По ссылке с именем автора открывается его публичный профиль. Владелец профиля может изменить описание через кнопку редактирования.
6. Кнопка выхода удаляет имя пользователя из сессии и возвращает на главную страницу.

## Ограничения текущей версии

Проект подходит для учебного запуска и демонстрации базовых возможностей Flask и SQLite. Перед размещением в интернете следует доработать безопасность и эксплуатационные настройки:

- заменить заданный в `app.py` постоянный `secret_key` на секрет из переменной окружения;
- хранить пароли в виде стойких хешей, а не открытым текстом;
- отключить `debug=True` в рабочей среде;
- выполнять удаление публикации запросом POST и добавить защиту от CSRF;
- добавить ограничения длины полей и уникальность имени пользователя на уровне базы данных;
- настроить обработку ошибок, конфигурацию базы данных и резервное копирование.

## Точка входа

Файл `app.py` содержит Flask-маршруты и является точкой входа в приложение. Файл `database.py` содержит функцию `create_database()`, которая создаёт или обновляет схему базы данных.
